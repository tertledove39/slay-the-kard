# 战役事件与历史关卡

## 内容规模

- `bin/event.ini`：50个事件。
- `cards/enemyTurn.ini`：50个历史战役关卡。
- `bin/AreaPool.ini`：将全部事件与关卡各一次分配到area2-9。
- `bin/HistoricalBattleNames.cs`：战役稳定ID对应的中文显示名称。

## 平衡约束

- 事件只使用 `none`、`replaceCard` 和 `replaceRandomCard`，确保与现有解释器兼容。
- 强力奖励通常搭配随机弱卡，或要求玩家牺牲原有卡牌位置。
- 每个事件有2至3个选项，并使用真实存在且可获得的卡牌ID。
- 每个战役使用6条行动；同一区域保持相近的部署频率和强化次数。
- 禁止 `everyNt=ADD:`，避免周期触发不断叠加永久行动。
- 当前50关复用既有12种敌军单位，没有为缺乏明确玩法差异的关卡强行新增单位。
- 后续若新增历史专属敌军，每关新增种类不超过2种，并优先跨相关关卡复用。

## 历史取材

关卡按时间覆盖布列斯特要塞、明斯克与基辅合围、莫斯科、列宁格勒、塞瓦斯托波尔、哈尔科夫、斯大林格勒、库尔斯克、第聂伯河、巴格拉季昂、雅西-基什尼奥夫、东普鲁士、维斯瓦-奥得、泽洛高地和柏林等东线战役。事件取材于工业东迁、坦克生产、租借法案、北极船团、铁路后勤、游击战、战地医疗、冬季作战和战时宣传。
